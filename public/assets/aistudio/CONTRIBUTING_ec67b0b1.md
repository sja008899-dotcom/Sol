# Contributing
1. قبل از PR: `gradle :app:testDebugUnitTest` باید سبز باشد.
2. قواعد سخت: دست نزدن به signingConfigs/applicationId؛ بدون مجوز یا endpoint جدید بی‌توجیه؛ بدون لاگ داده شخصی؛ بدون ابر.
3. نیت جدید = نمونه در `intents_fa.jsonl` + تست + مهارت + (اگر حساس است) ثبت در `NluSafety.SENSITIVE`.
4. هر عدد دقت را با داده و روش گزارش کنید.
