# Sol — دستیار صوتی و زندگی آفلاین فارسی

Sol یک دستیار اندرویدی **آفلاین‌محور** برای زبان فارسی است: حافظهٔ محلی (Room)، تشخیص گفتار آفلاین (Vosk)، مدل زبانی محلی اختیاری (LiteRT‑LM)، و اقدامات دستگاه که همیشه پیش از تماس/پیامک تأیید صریح می‌گیرند.

Sol is an offline-first Persian voice/life assistant for Android. No cloud AI, no analytics, no API keys.

## قابلیت‌ها (۲۳)
فهرست کامل داخل برنامه (صفحهٔ «قابلیت‌ها»). شامل یادآور، تماس/پیامک با تأیید، حافظه و نام‌های مستعار، ماشین‌حساب امن، تایمر، چراغ‌قوه، تقویم جلالی و ...

## معماری NLU
نرمال‌سازی → قواعد (با مرز کلمه) → طبقه‌بند n‑gram/TF‑IDF → پر کردن اسلات → مدیر گفتگو → رجیستری مهارت‌ها → (اختیاری) SLM با خروجی محدود.
لایهٔ آماری فقط اقدام‌های بی‌خطر و بدون اسلات را خودکار اجرا می‌کند؛ اقدام‌های حساس همیشه پرسش تأییدی دارند. جزئیات: [ARCHITECTURE.md](ARCHITECTURE.md).

## ساخت (بدون رایانه)
ساخت از طریق GitHub Actions انجام می‌شود: هر push یک APK دیباگ در بخش Artifacts می‌سازد. روی گوشی: Actions ← آخرین اجرا ← `Sol-Android-APK`. فایل `SHA256SUMS` را برای بررسی تطابق دانلود کنید.
ساخت محلی: JDK 21، Android SDK 36.1، Gradle 9.3.1 ← `gradle :app:testDebugUnitTest :app:assembleDebug`.
کوچک‌سازی R8 به‌صورت پیش‌فرض خاموش است؛ برای آزمایش: `-Psol.minify=true` (نیازمند تست روی دستگاه).
