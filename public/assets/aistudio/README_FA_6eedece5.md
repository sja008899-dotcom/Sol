# Sol — Source Release 1.0.0

## امکانات موجود در سورس
- رابط فارسی و راست‌چین، ورودی متنی و دکمهٔ میکروفون
- SpeechRecognizer اندروید با زبان fa-IR و درخواست ترجیح آفلاین
- Android TextToSpeech با درخواست صدای فارسی در صورت نصب بودن
- حافظهٔ محلی SQLite برای یادداشت‌ها، aliasها و تاریخچهٔ فرمان
- یادگیری عبارت: «هر وقت می‌گم دفتر، منظورم شرکت ... است»
- نمایش حافظه
- پیدا کردن مخاطب و باز کردن شماره‌گیر فقط پس از تأیید
- بدون مجوز اینترنت و بدون API ابری

## ساخت
Android Studio، JDK 17، Android Gradle Plugin 8.9.2، compileSdk 35، minSdk 26.
پوشهٔ اصلی را در Android Studio باز کنید، Gradle Sync و سپس Build > Build APK(s).

## محدودیت‌هایی که نباید اشتباه برداشت شوند
- EXTRA_PREFER_OFFLINE فقط ترجیح آفلاین است؛ تضمین تشخیص فارسی بدون اینترنت نیست. نتیجه به سرویس گفتار نصب‌شده روی گوشی بستگی دارد. برای آفلاین قطعی باید مدل محلی مثل Vosk به پروژه اضافه و آزمایش شود.
- جنسیت و طبیعی‌بودن صدا به voiceهای موتور TTS نصب‌شده بستگی دارد؛ صدای زنانهٔ فارسی تضمین‌شده نیست.
- تماس در این نسخه از طریق شماره‌گیر و با تأیید کاربر انجام می‌شود. تزریق صدای Sol به میکروفون تماس سیم‌کارتی در اپ عادی اندروید پشتیبانی تضمین‌شده ندارد.
- پیامک خودکار و شنود دائمی واژهٔ بیدارباش Sol در این نسخه فعال نیست.
- این نسخه سورس کاملِ قابلیت‌های ذکرشده در بالا است، اما تا زمان Build و آزمون روی گوشی، نسخهٔ تأییدشدهٔ نهایی محسوب نمی‌شود.
