# Privacy / حریم خصوصی

- Sol بدون سرور ابری کار می‌کند؛ هیچ تحلیل‌گر (analytics)، گزارش خطای ابری یا کلید API ندارد.
- گفتار با Vosk روی دستگاه تشخیص داده می‌شود. حافظه، مخاطبان و یادآورها فقط در پایگاه‌دادهٔ محلی برنامه ذخیره می‌شوند.
- تنها دسترسی شبکه: دانلود صریحِ مدل‌ها یا محتوای وب که کاربر درخواست می‌کند.
- تماس و پیامک فقط پس از تأیید صریح کاربر انجام می‌شود.
- داده‌های شخصی (نام، شماره، متن پیام) در لاگ نوشته نمی‌شوند.
- حذف داده: «فراموش کن» داخل برنامه یا Settings ← Apps ← Sol ← Clear data.
